Bilinen Eksikler / API Sınırları

  • Purview audit'te sensitivity_label_name API'de yok (field=NOT_EXPOSED_BY_API); yalnızca label_id mevcut.
  • MDCA upload hacmi tek başına 'hassas paylaşım' sayılmaz; Purview korelasyonu yoksa data_sensitivity=UNDETERMINED_REQUIRES_PURVIEW kalır.
  • agent_blueprint_id merge token'ı DEĞİL (relate-not-merge); aynı blueprint'ten türeyen birden fazla identity ayrı asset olarak kalır.
  • Defender for Cloud Apps (aggregatedAppsDetails) yalnızca kullanıcı/cihaz/IP SAYISI verir — bireysel kullanıcı/cihaz/IP kimliği bu API'de YOK; bu yüzden 'hangi kullanıcı/cihaz' sorusu yalnızca Purview etkileşimleri (gerçek kullanıcı kimliği taşır) üzerinden cevaplanabilir.
